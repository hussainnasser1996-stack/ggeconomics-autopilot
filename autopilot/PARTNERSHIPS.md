# GG Economics: partnerships plan (16 Nov 2026)

The audience is the asset; partnerships are the payoff. Researched 16 Nov 2026 (official program pages; rate figures are
vendor estimates except Collabstr's real transactions).

## Milestone ladder
| Followers | Unlocks | Action |
|---|---|---|
| 0 → 1k | Key platforms with no follower minimum | Apply: Keymailer (accreditation = regular, well-tagged gaming content), Terminals.io, Lurkit, Ubisoft Creators Program, Riot Creator Hub (next window), a **Steam Curator page** (devs send games via Curator Connect) |
| 500 subs + 3M Shorts views / 90 days | YouTube Creator Partnerships (ex-BrandConnect), Shopping affiliate, Studio Media Kit PDF | Join the moment it unlocks (the bar does not rise for this tier on 1 Feb 2027) |
| 1k–2k | Woovit (1k YouTube subs), Instagram creator marketplace (pro account; check Bahrain support), EA Creator Network (~2k typical) | Apply |
| 10k | Paid deals start (avg YouTube gaming deal ~$203 on Collabstr); CreatorDB Keydrop roster | Send the media kit to publishers' PR agencies |
| 50k | ~$1.5–3.5k per sponsored Reel (vendor benchmark) | Pitch publishers directly; rate card |
| 100k | Event invites, paid launch campaigns | Collabstr calls this the single most valuable step |

**Key programs reward coverage of a specific game.** Every couple of weeks, one Short is clearly about ONE game (e.g. its
cost-per-hour verdict) so key platforms accredit the channel.

No open creator programs found for Xbox, PlayStation, Nintendo (closed 2018), Capcom, Square Enix; SEGA/Bandai Namco are
per-game. Route in: their MENA/regional PR teams, with keys via Keymailer.

## Media kit (auto-generate monthly from analytics once there is data)
Positioning (gaming news through the money; finance-background founder) · 30/90-day Shorts views, avg views per Short,
viewed-vs-swiped, avg % viewed, subs gained; Reels vs carousel engagement · audience age/gender/countries (YouTube Studio
Media Kit PDF) · top 3–5 posts with numbers · packages + rate card (dedicated Short, mention, carousel, cross-post bundle,
usage rights) · past partners/keys · contact.
